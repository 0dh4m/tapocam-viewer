How to Access from Outside Safely

Option A: Cloudflare Tunnel (Zero Trust Access)
When you want to access this dashboard from any browser in the world without opening any router ports:
  1. Download cloudflared from Cloudflare.
  2. Run this single command in terminal:
cloudflared tunnel --url http://localhost:5000

You get a secure HTTPS link that routes straight to your PIN-protected dashboard with zero port forwarding!

Option B: Tailscale VPN (100% Invisible)
Install Tailscale on this PC and your smartphone. When outside, turn on Tailscale and navigate directly to:
http://[YOUR-TAILSCALE-IP]:5000

Your camera feed never touches the public internet. It remains fully encrypted end-to-end.
